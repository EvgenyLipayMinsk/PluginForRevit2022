# AerBIM

Используй исходники PluginForRevit2022 из текущего checkout или по пути из карточки проекта. Прочитай применимые инструкции репозитория. Для трассировки сложного поведения можно использовать aerbim-codebase-researcher.

Определи команду и аудиторию. Сверь названия кнопок, полей и сообщений с регистрацией команд, разметкой окон, ресурсами и обработчиками. Проследи предусловия, порядок действий, изменения модели и способ восстановления после ошибки.

При редактуре сохрани смысл и терминологию автора в пределах запроса. Для новой инструкции дай условия запуска, шаги, ожидаемый результат и действия при известных ошибках. Учитывай различия версий, если они подтверждены. При проверке перечисли расхождения со ссылками на источники и предложи исправленный текст. Пометь сведения, которые требуют проверки в Revit.
