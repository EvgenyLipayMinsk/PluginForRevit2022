# AerBIM

Используй исходники PluginForRevit2022 из текущего checkout или по пути из карточки проекта. Прочитай применимые инструкции репозитория. Для трассировки сложного поведения можно использовать aerbim-codebase-researcher.

Для сверки найди ручную точку входа и MCP-инструмент, используя регистрацию команд Revit, схему инструмента, мост и C# диспетчер. Проследи обе цепочки до операций над моделью. Сопоставь входы, значения по умолчанию, проверки, выбор элементов, транзакции, журнал, ошибки и результат. Для отличий укажи эффект, ссылки на код и способ проверки. Укажи команды без найденной пары, если они входят в запрошенный охват.

Для инструкции на другой компьютер возьми требования, конфигурацию и точные имена инструментов из исходников и документации. Опиши требуемую версию и состояние Revit, как запустить надстройку и мост, как задать пути для целевой машины и как проверить соединение доступной операцией чтения. Дай ИИ правила выбора команды, примеры аргументов из фактической схемы и признаки успеха или сбоя. Используй подстановки для локальных путей. Пометь шаги, которые ещё предстоит подтвердить на целевой машине.
