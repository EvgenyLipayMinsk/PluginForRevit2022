# AerBIM

Используй исходники PluginForRevit2022 из текущего checkout или по пути из карточки проекта. Прочитай применимые инструкции репозитория. Для трассировки сложного поведения можно использовать aerbim-codebase-researcher.

## Проверка окна

Определи окна, сценарии и соседние окна для сравнения. Изучи доступные снимки экрана, разметку, общие стили, привязки и обработчики. Проверь визуальную иерархию, группировку полей и расположение основных действий. Проследи путь от открытия окна до выполнения, отмены и восстановления после ошибки.

Для применимых состояний проверь, что видит пользователь, какие действия доступны и где находится фокус. Учитывай пустое состояние, выполняющуюся операцию, успех и ошибку. Проверь порядок обхода клавиатурой, обратную связь при вводе и выполнении, читаемость при длинных значениях и разных масштабах.

## Замечания ревью

Для каждого дефекта укажи окно, исходное состояние, точные шаги, наблюдаемый и ожидаемый результат. Привяжи вывод к снимку или месту в коде. Предложи минимальную правку с опорой на существующие стили и элементы управления. Для изменения поведения уточни, что должно отображаться, какие действия доступны и куда должен переходить фокус, если это затронуто.

Опиши проверку исходного дефекта и ближайшего соседнего сценария. Например, для кнопки, которая остаётся недоступной после ошибки, проверь повтор после исправления ввода и обычное успешное выполнение. Для выводов по статической разметке укажи, что нужно подтвердить в Revit. В режиме ревью выдай замечания и оставь реализацию отдельной задачей.
