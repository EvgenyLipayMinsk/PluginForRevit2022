# Проверка КЖ А3, версия 1.10.0.0

Поддерживаемые конфигурации: Revit 2021, 2022, 2023, 2024 (.NET Framework 4.8).

## Поведение

- Выбор текущего шаблона AerBIM или встроенной формы А3 на ленте; MCP: `form=aerbim|a3`.
- Вкладка «Полный КЖ» содержит все записи. Печатные вкладки ссылаются на неё формулами.
- Первый лист: 44 записи и большой штамп; продолжение: 49 записей и компактный штамп.
- А3, альбомная ориентация, область `A1:BU61`, нулевые поля, один лист Excel на одну страницу. Фиксированный масштаб 86% не применяется: это была отдельная проба.
- В начале и конце трассы нет добавленного `(эт. N)`; исходная маркировка устройства сохраняется.
- Последняя заполненная строка каждого печатного листа имеет чёрную нижнюю границу Medium.
- «УГО Вид Засечки» читается у каждого участка рассчитанного маршрута: «В лотке» → лоток; «Без засечки», «В ПВХ-канале», «В гибкой трубе», «В жёсткой трубе» → скрыто в трубе.
- Коэффициент, округление и запас распределяются пропорционально составу маршрута. Итог граф равен проектной длине; целый итог распределяется в целых метрах, дробный — до сотых с остатком в скрытой трубе.
- Служебные соединения, участки без параметра и длина при расчёте по прямой относятся к скрытой трубе. Неизвестное непустое значение параметра вызывает ошибку.
- Открытая прокладка, стояк и фактические данные остаются пустыми.
- Ручное редактирование значений распространяется на печатные листы. Добавление строк сверх выгруженного количества требует повторного экспорта. Согласованность длин после ручных правок проверяет пользователь.

## Автоматические проверки

Собрать `Release R2022`, затем выполнить `Tests\CableJournalForms\run-smoke.ps1`.

Проверяются 1/44/45/93/94/1203 строки, границы страниц и штампы, формулы и ручные правки, ноль и пустые ячейки, формат чисел, способы прокладки и их сумма, сохранность маркировки, нижняя граница, ошибки длины, блокировка файлов и защита шаблона AerBIM.

Проверка Graph компилирует его непосредственно из производственного исходника; вместо Revit XYZ используется числовая геометрия. Проверяются смешанный и обратный маршрут, разбиение ребра, выбор более короткого пути, отсутствие пути, временный мост и сброс предыдущего результата.

Проверки вне Revit не заменяют испытание на модели. После перезапуска Revit выбрать «АПС» → форму А3, проверить участок с лотком и маршрут с двумя способами прокладки. После экспорта проверить сумму граф и печать первой, второй и последней страниц. Excel и выбранный драйвер печати могут по-разному обрабатывать бумагу; размер PDF проверяется отдельно.

## Тестовые сборки и MSI

Тестовые DLL этой версии размещены в `bin\Test-1.10.0.0\R2021` … `R2024`. Для каждой используется соответствующая конфигурация `Debug R<год>` с параметром `/p:OutputPath=bin\Test-1.10.0.0\R<год>\`. Стандартная цель проекта регистрирует манифест текущего пользователя в `%APPDATA%\Autodesk\Revit\Addins\<год>`; уже запущенный Revit продолжает использовать ранее загруженную DLL до перезапуска.

После коммита общий MSI собирается `Installer\build-installer.ps1`. Он содержит Release-сборки 2021–2024. MSI не запускается автоматически. При переходе с локальной тестовой регистрации на MSI должна остаться одна регистрация AerBIM: пользовательская `PluginForRevit2022.addin` или установленная для всех пользователей `AerBIM.Manager.addin`.
