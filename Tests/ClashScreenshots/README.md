# Скриншоты коллизий Navisworks

В карточке выбранной коллизии: «Вставить скрин из буфера» (или Ctrl+V вне комментария). Повторная вставка заменяет скрин; «Убрать скрин» возвращает картинку исходного отчёта. Один пользовательский скриншот на коллизию, исходная картинка не перезаписывается.

PNG сохраняются в `<отчёт>.aerbim.json.images`, ссылки — в JSON статусов рядом с отчётом. Для совместной работы передавать отчёт, JSON и папку картинок вместе. При папке только для чтения используется `%APPDATA%\AerBIM\clashes`; локальные скриншоты доступны этому пользователю. При замене и снятии скрина старые PNG остаются в папке; экспорт использует только актуальный скрин.

Excel содержит встроенные изображения в столбце S «Скриншот» на листах «Коллизии» и «Исправлено». Изображение ограничено 320×180 пикселями с сохранением пропорций, высота строки подбирается автоматически. Если пользовательский скрин не добавлен, используется картинка Navisworks. Отсутствующее или повреждённое изображение отмечается текстом в ячейке; данные коллизии сохраняются.

`run-smoke.ps1` компилирует производственные источники без Revit, с заглушкой журнала замены ID. Проверяет PNG, повторное открытие, замену/удаление, относительные ссылки и перенос папки отчёта, старый JSON, сохранение комментария/скриншота при параллельных изменениях, профиль при папке только для чтения и отсутствие восстановления удалённого скрина. Для Excel проверяет встроенные байты PNG, привязку к строке, оба листа статусов, повреждённые/пропавшие изображения и сохранность заблокированного результата.

Ручная проверка после перезапуска Revit: открыть отчёт, сделать Win+Shift+S, вставить скрин, выбрать другую коллизию и вернуться, переоткрыть отчёт, выгрузить Excel и проверить картинку. Убедиться, что Ctrl+V в комментарии вставляет текст, а вне комментария — скриншот.
